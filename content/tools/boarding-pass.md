The boarding pass is one of the most recognisable document layouts in the world — which is why it is borrowed so often for things that have nothing to do with flying: wedding and event invitations, travel-agency itinerary summaries, "boarding pass" style gift vouchers, farewell cards for a colleague moving cities, classroom projects, and UI mockups for travel apps. This tool lets you design a **clearly-marked mock boarding pass** with passenger name, "flight" details, seat, gate and a decorative barcode, then export it as a PNG or PDF. It is a design template, not a travel document: it cannot be used to board a flight, and it must never be presented as a real airline's pass.

## Legitimate uses

- **Invitations**: "Boarding pass to our wedding — Destination: Goa, Boarding: 7 pm" is a popular save-the-date format.
- **Gift vouchers**: surprise a trip with a printed pass that reveals the destination.
- **Travel agents**: a branded itinerary card summarising the real flight the client has been booked on, sent alongside the airline's actual e-ticket.
- **Corporate events and offsites**: "Flight KGZ-2026 to Offsite" cards for delegates, with team and table numbers in the seat field.
- **Education and design**: teaching material, app prototypes, photography props.

For a real trip, the only valid boarding pass is the one issued by the airline at web check-in or the airport. A mock pass carries a decorative barcode with no airline data and prints "SAMPLE — NOT VALID FOR TRAVEL" by default.

## How to use the designer

1. Choose a layout — classic two-part stub, compact mobile-style, or invitation card.
2. Enter the passenger name, "from" and "to" (airport codes or any words), date, boarding time, seat, gate and a flight-style code.
3. Add your event or brand name, a logo, and a short message line ("Please arrive 30 minutes before boarding").
4. Pick a colour theme. The barcode is generated as a decorative pattern from the text you enter.
5. Download PNG for WhatsApp/Instagram or PDF for printing on 300 gsm card.

## Design notes

- The two-part layout has a perforation line; ask your printer for a micro-perforation and the stub tears off like the real thing.
- Keep names in capitals and use a monospace font for codes — that is what makes the format instantly recognisable.
- For invitations, put the venue map link in a real QR made with the [URL QR generator](/tools/url-qr) so guests can navigate; the decorative barcode is not scannable on purpose.
- Compress photos before placing them with the [photo resizer](/tools/photo-resizer).

## For travel agencies: the honest itinerary card

Agencies should send the airline's e-ticket and PNR as the official document and use the mock pass only as a **summary card** with the agency's own name on it. Never reproduce an airline's logo, and never issue a document that could be mistaken for a boarding pass at security. Add "Itinerary summary — check in with the airline" as the message line. ## FAQ

### Can I use this to make a boarding pass for an actual flight?

No. Only the airline issues a valid boarding pass, and airport security verifies it against the airline's system. This tool prints a sample marked not valid for travel.

### Is it legal to make a mock boarding pass for an invitation?

Yes, as long as it does not use a real airline's name, logo or branding and is not presented as genuine. Use your own event name in the airline field.

### Does the barcode scan?

No. It is a decorative pattern. If you want guests to scan something, add a real QR code linking to a map or RSVP form.

### What size should I print?

The classic pass is about 20 × 8 cm; the invitation layout is A6. Use 250–300 gsm card and, for the stub, a perforated cut.

### Can I add a photo or logo?

Yes — upload a logo for the "airline" area and optionally a background image for the invitation layout.
